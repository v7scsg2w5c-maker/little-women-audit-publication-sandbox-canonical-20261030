# Letter postbody containment

Wrap the fifteen selected letter endings in &lt;footer role="presentation"&gt;, retaining their existing signatures, valedictions and postscript. Manual §7.7.4.1 groups postbody letter material in a footer and requires presentational roles inside blockquotes. These changes establish that structural boundary without rewriting the closing text. The table identifies each selected ending.
