# Capitalize kinship terms used as personal names

Capitalize kinship terms at 249 places where they function as personal names. These remain discretionary editorial modernizations under the scoped kinship policy: SEMoS §8.3.1 supplies general modern-style guidance, while the retained CMoS 18 §8.37 paraphrase is supplementary and does not establish mandatory force.

The 1,441 examined kinship uses contain 249 proposed changes and 1,192 preserved readings. The additional name uses include Grandpa, Aunt/Aunt’s, Mamma, Uncle, Grandfather and Papa. Ordinary relational uses retain their existing readings.

Confidence: 244 high; 5 medium.

The broken phrasing around ‘Grandfather’ in chapter 35 leaves address versus reference less certain; capitalization remains a recommendation under either reading.
