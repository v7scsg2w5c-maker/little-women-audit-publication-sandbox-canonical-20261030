# telegram class and style

Add class="telegram" to the chapter 15 message beginning “Your husband is very ill. Come at once,” and add .telegram { font-variant: all-small-caps; } to local.css. The preceding narration expressly identifies it as a telegraph message. The Manual requires this class and presentation for telegram letters (high confidence). Both edits form one technical correction.
