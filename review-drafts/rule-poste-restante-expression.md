# poste restante expression

In Amy’s Heidelberg letter in chapter 31, change Post Restante to Poste Restante. The retained lexical assessment favors the conventional French postal expression for the place where Fred collects letters. This is an optional spelling normalization with medium confidence; the existing historical form remains intelligible and has not been established as a source error. The proposal adds only the e and makes no broader language-markup or capitalization change.
