# little women self reference

At the end of chapter 23, style the narrator’s reference to Little Women as a book title: replace “&lt;b&gt;Little Women&lt;/b&gt;.” with &lt;i epub:type="se:name.publication.book"&gt;Little Women&lt;/i&gt;. The reference to the reception of this first act supports the title reading, for which publication italics and omission of redundant quotation marks are appropriate. The domestic-drama metaphor also permits the present reading. This is a discretionary editorial interpretation with medium confidence, not a demonstrated source error.
